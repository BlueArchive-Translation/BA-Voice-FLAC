## 📁 目录组织方式

- 文件命名严格对应原版游戏资源结构（如 `Main_41090.zip`，内含角色/剧情对应的全量高清 `.flac` 音轨）。
- 解除了原版的密码混淆，任何音频播放器、剪辑软件或二次开发工具均可直接打开解压。

### 📌 韩配分卷说明 (Multi-part Archives)
- 韩服原版整合包（如 `11.zip`、`34.zip` 等）包含数千条语音，超清还原后单包体积达 300MB~875MB。
- 为适配 GitHub 单文件 100MB 限制并方便高速分发，已科学切分为 `11_part01.zip`、`11_part02.zip` 等独立标准包（单包均严格控制在 75MB 以内）。
- 解压同一前缀的所有 `part*.zip` 到同一文件夹即可自动还原该章节全部无损音轨。
